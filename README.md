# Top 100 Blu-ray 3D — Stremio Catalog

Static Stremio catalog using the same structure as `A-A-prod/top-romcoms`.

## Install through GitHub Pages

1. Create a public GitHub repository.
2. Upload the contents of this folder, preserving the paths.
3. Enable GitHub Pages from the `main` branch and repository root.
4. Add this URL in Stremio:

`https://YOUR-USERNAME.github.io/YOUR-REPOSITORY/manifest.json`

## Catalogue rules

- Feature films only.
- Titles selected from movies with Blu-ray 3D editions.
- 100-title practical IMDb-rating-based selection.
- Display order is newest to oldest, rather than rating order.
- IMDb ratings change, so the cutoff should be periodically refreshed and audited.
