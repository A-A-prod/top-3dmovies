# Top 100 3D Movies

Static Stremio catalog for the 100 highest-rated movies released on Blu-ray 3D, displayed from newest to oldest.

## Repository

https://github.com/A-A-prod/top-3dmovies

## Stremio manifest

https://a-a-prod.github.io/top-3dmovies/manifest.json

## Files to upload

- `manifest.json`
- `catalog/movie/top-100-3d-movies.json`
- `movie-list.csv`
- `README.md`

## GitHub Pages setup

1. Upload all files while preserving the folder structure.
2. Open **Settings → Pages** in the GitHub repository.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the `main` branch and `/ (root)`.
5. Save.
6. Install the manifest URL in Stremio:

   `https://a-a-prod.github.io/top-3dmovies/manifest.json`
